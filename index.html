GITHUB PAGES 무료 실시간 DB 연결 방법
  1. console.firebase.google.com 접속 → 무료 프로젝트 생성
  2. Build → Authentication → Sign-in method에서 Anonymous(익명) 사용 설정
  3. Build → Firestore Database → Create database 생성 후 Rules 탭에서 allow read, write: if request.auth != null; 게시
  4. 프로젝트 설정의 웹 앱(</>) firebaseConfig 값을 복사해 코드 내 USER_FIREBASE_CONFIG에 붙여넣거나 아래 칸에 입력 후 연결하세요.

FREE iOS WIDGET SETUP (SCRIPTABLE)
  1. App Store에서 무료 앱 Scriptable 설치 후 우측 상단 + 버튼을 눌러 새 스크립트를 만듭니다.
  2. 스크립트 이름을 DailyPlanner로 지정하고, 위 COPY WIDGET SCRIPT 버튼을 눌러 복사한 코드를 붙여넣고 저장합니다.
  3. 아이폰·아이패드 홈 화면에 Scriptable 위젯(S/M/L/XL)을 추가하고 Script: DailyPlanner로 설정합니다.
  4. 플래너 작성 후 상단 SYNC iOS 버튼을 누르면 현재 할 일 목록이 실제 iOS 위젯에 즉시 반영됩니다.
