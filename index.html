iOS WIDGET
FREE iOS WIDGET SETUP (SCRIPTABLE)
  1. App Store에서 무료 앱 Scriptable 설치 후 우측 상단 + 버튼을 눌러 새 스크립트를 만듭니다.
  2. 스크립트 이름을 DailyPlanner로 지정하고, 위 COPY WIDGET SCRIPT 버튼을 눌러 복사한 코드를 붙여넣고 저장합니다.
  3. 아이폰·아이패드 홈 화면에 Scriptable 위젯(S/M/L/XL)을 추가하고 Script: DailyPlanner로 설정합니다.
  4. 플래너 작성 후 상단 SYNC iOS 버튼을 누르면 현재 할 일 목록이 실제 iOS 위젯에 즉시 반영됩니다.
